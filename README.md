# WebNav

运行在本机的单用户服务器与工作区导航页。使用分组、搜索和收藏管理服务器及网站，在浏览器打开 SSH、RDP、VNC、本地终端和设备画面，也可启动本机 Windows 远程桌面。插件中心支持替换内置功能及下载主题。

[MCP 工作台接入](docs/mcp-implementation.md)：插件可选声明 AI 能力，本机 AI 通过标准 stdio 接入；统一授权、后台 SSH、SFTP 文本修改、AI 标签只读观察与人工接管，任务结束自动释放连接。

[Harness 更新与插件调研](docs/harness-updates-research.md)：官方实现对照与插件更新预览改进。[正式版在线更新](docs/online-updates.md)已实现独立运行包、签名验证、任务收尾、失败恢复与稳定自启入口；Gitee 源读取普通发行版页面并缓存、退避，正式发布流程见文档。

## 当前功能

- [插件 Worker](docs/plugin-workers.md)（0.1.2）：后端默认共享 Worker，声明 `execution.backend: dedicated` 后独占；主线程负责入口转发与监测，不加载插件业务。任务管理器与系统优化各使用一个独占线程，其余内置及随附插件使用默认共享线程，插件中心显示实际位置。共享线程阻塞影响同组业务，前端渲染和进程级故障不属于此隔离保证。

[公开控件与界面扩展](docs/plugin-ui-extensions.md)：插件可声明菜单、标签页、面板、操作栏，以“插件 ID/控件名”定位；默认公开，手动 `public: false` 后禁止其他插件查找或插入。声明含用途与字段说明，并生成 [静态扩展点表](docs/plugin-ui-catalog.md) / [JSON](docs/plugin-ui-catalog.json)。任务管理器及终端、文件、工作区菜单已接入，其他插件可添加操作和详情标签，不必逐个修改框架。2026-10-28 本批：10 项扩展机制测试、4 项平台测试、独立插件浏览器联动及任务管理器菜单回归通过；前后端类型检查与前端构建通过。均为隔离数据与模拟目标，未实现或运行真实调试器。

架构目标见[通用插件平台与插件间通信](docs/plugin-platform.md)，通用注册与通信首版已实现；更多插槽及旧内置服务全面拆包仍属后续范围。审查问题与修复状态见[框架审查](docs/plugin-framework-audit.md)。

[通用插件 SDK 首版](docs/plugin-sdk.md)：独立插件可注册左侧工具、工作区、可选设置页、命名字体和后端公开服务/状态订阅。插件中心默认已安装，总览与插件内设置按钮共用草稿；停用保留配置入口，卸载撤销展示并保留本地文件和配置。历史内置服务仍有固定槽兼容层，不宣称已全部拆包。

- [浏览器自动填写](docs/browser-extension.md)：Chrome / Edge / Firefox 扩展从本机 WebNav 获取网页收藏账密，也可点击读取当前网页和已输入账密，确认后新增或更新 WebNav 收藏；独立一次性配对、双向认证与加密 WS、逐网站授权、自动填写和撤销。HTTP / HTTPS 按相同域名匹配，非默认端口区分。全局设置提供扩展安装包和配对管理，Firefox 当前为未签名开发包。

- [本地终端 / 安卓 ADB / WDB](docs/local-adb-wdb.md)：三个内置插件接入插件中心。Local 自动选择系统 Shell，也可选 PowerShell / CMD；ADB 默认推送随附的官方 scrcpy server，支持连续视频、触摸键盘与中文粘贴；WDB 连接被控端网页服务，提供 H.264 桌面和按需开启的键鼠控制。

- [插件中心](docs/plugins.md)：公开 Git 地址安装、提交锁定、安装前风险确认、17 个固定分类、宿主平台检查、启用 / 默认实现 / 回退 / 恢复内置。内置插件与官方、第三方扩展统一展示；图标、README 与仓库持久缓存。默认热插拔与热更新，相关连接使用中时等待结束后自动切换，无法在线替换时提示待重启及原因；独立「主题」分类支持下载配色与背景并立即应用，提供可独立发布的服务替换和纯主题示例。

- [配置同步](docs/config-sync.md)：全局设置与插件中心均可打开，GitHub / Gitee 保存本机加密快照，自定义同步账号密码解密；支持可选凭据、三方冲突、历史恢复、换密码及解锁期间自动同步。恢复配置不自动连接服务器或安装、启用第三方插件。
- [远程 VS Code](docs/remote-editor.md)：文件栏打开当前目录，Linux 用 code-server、Windows 用 VS Code Server Web，经 SSH 转发到独立浏览器页；首次下载缓存、后续复用，也支持预缓存离线包。
- Vue 3 导航与独立管理页：服务器多入口、批量操作、最多 5 层分组、固定宽度卡片、主题与左右独立背景；内置 imagegen 风景皮肤[雾岚湖畔](docs/design/mist-lake-skin.md)。
- 首页网页收藏：圆角截图卡片、新标签页打开网站、单独保存和查看账密。有主密码时每次查看都重新验证；截图复用本机 Edge/Chrome，生成后缓存，支持手动刷新，不自动登录网站。
- Cordis 本地服务，Hono 提供页面，业务通信全部使用 WS。目录保存在 SQLite，刷新与重启后保留；初始目录为空，不加载演示服务器。
- Windows 无主窗口托盘：启动命令自动在后台运行前后端，右键打开主页、勾选开机启动、重启、退出；悬停提示和菜单显示 SSH、网页 RDP 等运行数量，全部为零显示“暂无运行”。同一用户仅运行一个工作台，重复启动自动打开已有网页，开发、正式和前台调试模式共用实例。
- [后台会话](docs/persistent-sessions.md)：刷新或关闭浏览器后，SSH / 本地终端和内置网页桌面、设备连接继续由后端持有；同一浏览器重新打开时接回原连接及分屏。明确关闭标签才释放，后端退出或重启仍结束连接。
- 管理中心“导入本机 SSH”：读取当前用户的 ~/.ssh/config，预览后事务替换目录，保存用户名、端口和私钥文件引用；不自动连接，不猜测操作系统或自动添加 RDP。
- [SSH 工作区](docs/terminal-workspace.md)使用 ssh2 + xterm.js，支持主机指纹确认、密码或私钥认证。一个主标签管理一组终端，可嵌套上下 / 左右分屏、拖动分隔线、最小化窗格、悬浮和独立显示；切换展示不重连，关闭主标签释放整组。默认 2,000 行滚动历史和累计字节 ACK，全局或单入口配色更新不重建终端。
- 右上角“全局设置”统一管理主密码：默认 Base64 可逆编码，设置主密码后所有已存密码统一迁移为 scrypt + AES-256-GCM 加密。首次访问统一解锁，有效期支持分钟、小时、天或服务运行期间永不过期；刷新与新标签共享有效期。私钥文件保持原路径。
- 独立“查看历史”对话框：选择会话、固定查询范围、搜索、分页和手动刷新。后端保存纯文本，不保存原始终端录像。
- 系统 Windows RDP 在编辑入口中直接填写密码，与服务器配置一起事务保存；每个入口独立选择窗口分辨率（预设或自定义）、单屏全屏或所有显示器全屏。启动时向 Windows 传递已保存凭据并用 mstsc.exe 打开，只报告“客户端已启动”。仅显式选择系统客户端的 RDP 入口使用该方式。网页入口使用已校验的 HTTP(S) URL。

- 内嵌 RDP / VNC：复用标签页和悬浮窗口，支持缩放、全屏、组合键与手动文本剪贴板。VNC 密码和 RDP 密码遵循同一全局主密码规则；桌面每 5 秒采样缩略图，关闭保留最后画面。新旧 RDP 入口均默认网页内嵌，点击直接打开工作区标签，无需逐个改配置；仅明确选择系统客户端的入口调用 mstsc。

网页 RDP 由独立 Cordis 插件调用随项目附带的 Windows x64 FreeRDP 组件；运行时自动校验和解压，连接时启动，关闭时回收。不需要 Docker、WSL 或另起网关，仍使用 `pnpm dev`。VNC 由 Node 直接连接。兼容范围、源码编译和验证边界见[网页桌面](docs/embedded-desktops.md)。

网页 RDP 默认固定 1920 × 1080，保留各入口已保存的分辨率，最高 4096 × 2160。同一次更新的变化区域一起显示，大面积运动使用 JPEG，局部小变化及停止后的精修使用无损 PNG；最多两帧等待浏览器确认，后续变化合并到最新画面。桌面工具栏显示实际分辨率与绘制帧率，测量含义、模拟基准和复现方式见[刷新性能对比](docs/embedded-desktops.md#刷新性能对比)。

SSH 支持系统信息侧栏和 SFTP 文件管理，可独立关闭 / 打开：文件右键、上传下载、ZIP 压缩解压、浮动代码编辑与本地编辑回传。分屏标题带编号，文件栏点击对应编号定位并跟随目录，手动浏览会暂停跟随，见[SSH 文件管理](docs/ssh-files.md)。导航可调宽、收起并从左侧悬浮展开。SSH / 本地终端卡片截图、.rdp 下载与跳板机尚未实现；会话恢复限同一后端运行期，AI 后台任务仍按 MCP 任务生命周期管理。最近使用和最后画面暂为本页状态。RDP / VNC / ADB / WDB 合计最多 4 个画面，与终端合计最多 8 个连接，浏览器关闭后仍占用额度；这些限额与历史存储额度不代表已完成容量压测。

默认[公开插件索引](https://gitee.com/axisxy/webnavpluginsmarket)只收录插件地址与发现信息，没有账号、评分或评论。内置说明和图标读取当前项目，第三方说明和图标读取各自仓库并持久缓存；来源标记不代表安全审核。安装前显示数据、账号和远程操作风险，并建议先用 AI 审查源码与安装步骤。热更新只在用户确认后切换，不会自动执行仓库最新代码。

## 运行

已验证 Node.js 24.16.0、pnpm 12.4.2。首次运行：

~~~powershell
pnpm install
pnpm build
pnpm start
~~~

打开 http://127.0.0.1:3030/ ，导航页面自动连接本机服务，无需配对。没有设置主密码时直接进入；设置了主密码且尚未解锁时输入主密码。独立浏览器自动填写扩展需单独安装、首次配对并按网站授权。

开发只需运行一次：

~~~powershell
pnpm dev
~~~

根目录与 `frontend/` 下的 `pnpm dev` 都会启动前后端（`npm run dev` 调用同一入口）。Windows 上就绪后命令返回，右下角显示 WebNav 托盘，此时可以关闭终端；右键提供“打开主页 / 开机启动 / 重启 / 退出”，双击也可打开主页。开机启动默认关闭，勾选后在用户登录时生效。直接打开 http://127.0.0.1:5173/ ，管理中心地址为 /#manage，插件中心地址为 /#plugins。

更新 WebNav 宿主后端代码或启动环境变量后，从托盘选择“重启”；生产模式先重新 `pnpm build`。数据库保留，活动网页连接会断开。插件中心的安装、启停和更新默认在线生效，只有界面明确显示“待重启”时才需要稍后重启；相关资源使用中则等待结束后自动切换。升级宿主本身仍需重启，不能由插件热更新代替。

重复运行 `dev`、`start` 或 console 命令会自动打开现有实例的实际网址，不创建另一套服务；更换仓库目录、端口或 `WEBNAV_DATA_DIR` 也不绕过此限制。需要切换参数时先退出再启动。本次单实例启动器升级需完整退出旧工作台后重新启动。

正式运行的 `pnpm start` 同样使用托盘，退出也从托盘操作。首次从旧版终端运行迁移时先关闭旧服务，避免端口占用。需要前台日志时用 `pnpm dev:console` / `pnpm start:console`，Ctrl+C 退出；非 Windows 默认前台运行。详细说明见[Windows 托盘](docs/windows-tray.md)。`pnpm dev:ui` 仅用于已有后端的前端单独调试。

数据未加载时显示“目录尚未加载”，不显示 0 台或“还没有服务器”；连接中断时保留本页上次读取的目录，并暂停目录操作。浏览器缓存不是数据库；Windows 默认目录数据库为 `%LOCALAPPDATA%/WebNav/webnav.sqlite`，与从哪个代码目录启动无关。

~~~powershell
pnpm typecheck
pnpm test
pnpm build
~~~

类型检查与构建覆盖四个工作区；`pnpm test` 先构建 shared，再运行 backend、frontend 和 extension 测试。shared 当前没有独立测试脚本，浏览器验收脚本需按对应功能文档单独运行。

Windows 数据默认在 `%LOCALAPPDATA%/WebNav/`；没有 LOCALAPPDATA 时使用 `~/.local/share/WebNav/`，可用 `WEBNAV_DATA_DIR` 改变。`WEBNAV_PORT` 默认 3030，`WEBNAV_UI_PORT` 为开发页面端口，默认 5173。生产静态资源与业务 WS 同源，服务器只监听 127.0.0.1。第三方插件导致启动异常时，可设置 `WEBNAV_DISABLE_PLUGINS=1` 后重新启动，以内置实现恢复访问；安装记录、配置和插件数据仍保留。

## 目录与文档

[系统优化独立插件](docs/system-optimizer.md)（2026-10-28，官方内置首版）：位于 `plugins/system-optimizer/`，通过公共 SDK 注册左侧入口、右侧工作区、设置和字体；提供本机 Windows 11 x64 启动登记查询、当前用户普通 Run 项停用/恢复、10 项用户设置、应用清单、Windows 存储入口及加密恢复记录。真实系统写入尚未验收，文件清理与启动文件夹写入仍待适配；随 WebNav 自动提供，无需从 Git 安装；支持禁用、卸载和发现页恢复安装，卸载状态跨重启及更新保留。此次未重启日常实例。文档保留开源调研、概念图及实际界面截图。

新增[任务管理器插件](docs/task-manager.md)：从「工具」打开，选择本机或已保存的 SSH 目标，缺少采集器时点击自动安装到目标用户目录 `.webnav/tools/task-manager`。提供进程树/列表、按平台可用的详情与确认后结束进程；0.2 增加清晰的面板分层、CPU/内存绿黄橙红热度、进程/性能视图切换、逐逻辑处理器、磁盘吞吐与 GPU 性能，专用显存和共享系统内存分别显示。Windows/Linux/macOS 的驱动适配和实际验证范围分别记录。源码首次使用运行 `pnpm collector:build`；高级资源搜索、事件追踪与系统任务管理器快捷键接管仍为后续设计。

0.3.1 支持复选框多选及「只看勾选进程」，固定观察各进程的 CPU、内存曲线和内存增量；工具栏提供复制 PID/清单、清空和确认后批量结束。点击进程可在「概览 → 启动参数」读取、刷新和复制完整命令行，不进入快照或历史。使用与限制见[多进程观察与启动参数](docs/task-manager.md#多进程观察与启动参数031)。

0.3 增加可选[持续监控与历史回溯](docs/task-manager.md#持续监控与历史回溯)：目标独立记录，关闭 WebNav/SSH 后仍采样，重新连接可查看卡顿时的性能和高占用进程。默认每 5 秒、最多 7 天/256 MiB，可调整；查看历史使用固定范围与峰值代表点，历史进程只读。停止持续监控保留记录；本轮不自动注册系统自启，目标重启或登录策略终止后台进程时会明确显示间断。

性能与历史曲线使用细蓝线、浅蓝填充和淡色密网格，支持浅色/深色主题；历史图显示实际起止时间，填充不跨越采样缺口。

- `frontend/`：Vue 页面、业务 WS、终端和桌面工作区、插件与主题视图。
- `backend/src/`：Cordis 装配、HTTP/WS、SQLite、凭据、连接与同步服务；`plugin-system/` 管理外部插件安装及运行生命周期。
- `backend/plugins/`：内置插件清单、图标和说明；`backend/native/`：随项目提供的原生辅助组件。
- `extension/`：Chrome / Edge / Firefox 自动填写与收藏保存扩展，独立构建和测试。
- `shared/`：公开 DTO、格式校验与跨端消息契约，不包含后端实现或凭据。
- `examples/plugins/`：可独立发布的服务替换、纯主题示例，不写入运行目录或充当真实市场条目。
- `scripts/`：开发、生产、缓存准备入口；`docs/`：架构、使用和验收说明，设计资料位于 `docs/design/`。
