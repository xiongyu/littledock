# SSH 工作区、右键菜单与配色

## AI 终端（首版已实现）

[MCP 实施说明](mcp-implementation.md)记录 AI 发起的 SSH 终端：进入现有标签和分屏体系，主标签/窗格保留 AI 标记，默认不抢焦点。用户可查看 AI 实际使用的同一 PTY 输入输出，也可切换标签或最小化后不看；画面按远端回显显示，不强制暴露密码输入。

默认人工只读，可选择、复制和翻阅；键盘、粘贴、中断及远端鼠标输入由前后端共同阻止。点击“解锁输入”取得该终端唯一人工输入权，暂停 AI 的后续输入及关联新动作，已运行命令不自动中断；用户可以正常输入命令或 Ctrl+C。点击“锁定并交还 AI”恢复只读，AI 重新读取状态再继续，不重放旧输入。人工接管后标签仍保留 AI 来源标记。

AI 会话由后端任务租约持有，观察页面断线/刷新不结束远端 PTY；若人工控制页面离线则撤销其输入权，等待显式交还。明确关闭终端或整组标签会结束相应 AI 会话与关联任务，“不看”通过切换/收起实现。AI 观察者使用有界当前状态同步和独立 ACK，不能复用单一网页 WS 的所有权。普通终端也支持[后台会话恢复](persistent-sessions.md)，但不使用 AI 的任务收尾或人工接管租约；AI 额度和验收以 MCP 实施说明为准。

“不看”仅表示不提前中断仍在执行的任务。整个 AI 工作完成、失败或取消后自动收尾并释放专属 SSH，无需点开标签或手动关闭；可保留有界的“已结束”只读结果标签，它不占活动连接额度。人工正在接管时显示“AI 已结束，人工仍在使用”，由人工租约继续持有，交还或关闭后立即回收；只读观看不会阻止自动结束。

## 使用

- 一个主标签管理一组终端，分屏成员不重复占用顶部标签；主标签旁的小数字显示组内终端数。关闭主标签或选择“关闭整组终端”，关闭该组全部会话，包括移到悬浮窗口或独立显示页的成员。
- 每个窗格的小标题支持右键 / Shift+F10：重连、连接配置、悬浮 / 收回、独立显示页、左右分屏、上下分屏、移到单独标签和关闭当前终端。关闭一个窗格只释放该会话，其余窗格自动补满空间。主标签右键中的连接操作作用于组内当前终端，关闭作用于整组。
- 可对任意 SSH 窗格继续分屏。例如先左右分屏，再对左侧小标题选择上下分屏，得到左上、左下、右侧三个终端；还可以继续拆分其他窗格。RDP / VNC 不参加分屏。总会话限制仍是 8 个，分屏中的每个终端均占一个会话额度。
- 分屏候选仅来自其他标签，不包含本组已有窗格；没有候选就直接新建同一连接，只有一个候选直接移入，有多个才显示选择列表，也可新建同一连接。移入保留原 SSH 连接和输出，来源标签没有剩余终端时自动移除。
- 每条分隔线独立调整所在区域的比例：可拖动、双击均分、聚焦后用方向键调整，比例限制为 20%–80%。悬浮或移到独立页时，其余窗格填满空位；收回恢复原来的分屏位置和比例。
- 浏览器变窄或变矮时，容器和 xterm 行列数随之调整；默认字体保持 13 px，不通过缩放文字来适应窗口。字号只由终端菜单的放大、缩小或恢复操作修改。
- 终端区域的右键和 Shift+F10 打开专用菜单：复制、粘贴、全选、中断命令、回到底部、历史 / 搜索、字号、配色、连接配置、重连与关闭。无选区时禁用复制，未连接时禁用粘贴和中断。
- Ctrl+Shift+C 复制，Ctrl+Shift+V 粘贴；Ctrl+C 发送中断，不作为复制快捷键。粘贴调用 xterm 的 `paste`，保留 bracketed paste 行为，并继续受输入长度和流量限制约束。剪贴板权限失败时提示可采取的操作，不伪装成功。
- 普通 SSH / 本地终端超时、连接失败、远端退出或通道断开后，保留原有输出和原因，显示「按 Enter 重新连接」。只在该终端获得键盘焦点时响应无修饰键的 Enter，按住重复、输入法确认、搜索框和其他终端输入不触发；连接中和已连接时不作为重连键。业务连接离线或锁定时提示先恢复服务或解锁；重连沿用现有显式连接流程，只替换当前会话，不向新 Shell 补发这次回车。AI 终端仍按任务生命周期管理。
- 查看历史仍打开原有独立只读历史对话框，支持查询，不向实时终端补写历史。
- 分屏标题的最小化按钮只收起画面、保留标题，不关闭 SSH，也不停止有界输出解析。上下分屏缩为 36px 标题栏，另一侧补满；左右分屏缩为 36px 标题竖条。点击还原恢复原比例；所有窗格收起时仍可逐个还原。
- 导航边界可左右拖动（164–400px，双击恢复 232px）。顶部导航按钮可收起到零宽度；鼠标进入页面最左侧 20px 时浮出导航，离开导航范围收回，不挤动正文。根据鼠标坐标判断，不依赖狭窄覆盖层或动画中的边界事件；窄窗口使用鼠标同样支持，触摸操作保留按钮。再次点击顶部按钮可固定展开并恢复此前宽度。

2026-10-26 悬浮回归：使用浏览器鼠标移动事件（不点击）验证 1280px 和 680px 视口，指针移到 x=12 时展开，移到导航内部继续保持，移到正文后收回；展开期间正文左边界保持 0。修复前 x=12 无法触发，窄窗口则被样式完全禁用。
- SSH 左侧系统信息和底部文件栏各自可以关闭，通过顶部 CPU / 文件夹图标重新打开。系统信息跟随当前窗格；每个分屏标题显示编号，文件栏的数字按钮定位并跟随对应终端，手动浏览会暂停。系统信息栏可拖宽、文件栏可拖高，宽高偏好保存在浏览器，详情见[系统信息与文件栏](ssh-inspector.md)。

## 独立显示页的生命周期

SSH 独立页使用同源新页面和随机握手标识，把现有 Vue 终端视图搬到该页面。URL 不包含绑定票据、终端输出或凭据。页面间校验消息来源、精确 Origin 和标识；只传送就绪通知。

此方式保留同一个 xterm 实例、SSH 会话、输出解析队列和累计 ACK。xterm 按官方 API 再次调用 `open` 更新窗口归属，字号、有限滚动历史和输入保持可用；关闭独立页或点击“收回标签页”将视图搬回主页。弹窗拦截或加载失败不关闭原终端。

独立页的显示实例依赖原主页；关闭或刷新原主页会回收独立显示窗口，后台 SSH 继续运行。重新打开主页后接回原会话并恢复主工作区布局，不自动重开独立窗口。独立页自身刷新会收回视图；直接打开独立页地址只显示返回主页入口。终端缓冲与认证资料不放入浏览器存储。浏览器如何将新页呈现为标签还是窗口由其设置决定，可拖出到另一个显示器。

## 配色

右上角“全局设置 → 终端配色”提供独立配色界面。内置静谧森林、午夜蓝、石墨灰、暖纸白；可从任意方案新建、改名、修改或删除自定义方案，最多 64 个。编辑支持背景、文字、光标、选中背景及 ANSI 16 色，带即时示例预览；保存后才应用到运行终端。关闭未保存编辑会询问是否保存。

`terminal-themes` Cordis 服务把配色保存在 SQLite settings；读取、保存和订阅都走业务 WS，遵循主密码解锁、版本冲突检查和操作去重。与服务器目录分开保存，目录整体替换不会删除配色。普通目录 JSON 包含 SSH 的 `terminalThemeId` 引用，不携带自定义配色定义；在另一个安装中不存在该方案时使用其默认配色。

每个 SSH / 本地终端入口可以选具体配色，或跟随全局默认。终端内右键“终端配色…”打开当前入口的配色面板，显示服务器和连接名称，可预览并保存当前连接的方案；同一入口的所有已打开终端一起更新，其他入口和全局默认不变。服务器编辑中的“终端配色”仍可在连接前配置。旧入口默认跟随。

当前连接面板的“管理配色方案”进入全局方案管理，可新建、调整自定义颜色，保存后“返回当前连接”选用。方案定义为共享资源，修改某个方案会更新所有引用它的入口；需要独立颜色时先新建方案。切换或关闭未保存选择仍会询问是否保存。当前入口被删除、服务断线或锁定时禁止保存；入口配色已被其他页面修改时提示重新打开，其他无关目录修改在保存时保留。

已删除 / 导入后缺失的方案回退到全局默认；默认方案删除时回退到静谧森林。配色选择经现有 `catalog.replace` 与目录一起保存，保留版本校验与操作去重，不另增业务 HTTP 接口。修改 `terminal.options.theme` 即时更新显示，不重新连接、不重建 xterm，不改变 scrollback 或 ACK。

## 标签分组与嵌套分屏验证（2026-10-26）

布局使用二叉分屏树保存窗格归属、方向和比例，渲染时计算平面的窗格矩形。Vue 终端视图始终按 sessionId 保持在同一层级，树结构改变不重新挂载 xterm 或重建 WS。悬浮和独立页只从当前布局计算中排除，归属仍保留，以支持主标签整组关闭。连接创建期间主标签已关闭时，迟到的新会话会立即释放。

- 本机模拟服务验证同一主标签内三个 SSH：左侧上下分屏、右侧保持整块。左侧局部分隔条从 50% 拖到 36%，右侧尺寸不变；900×600 下三个窗格均保持 13px 字体，无页面横向溢出。
- 从已有标签移入、移到单独标签再合并，已有会话 ID 不变；单窗格重连只更换该 ID，其他 ID 和分隔比例保持。关闭单窗格后自动补满，关闭主标签后模拟服务活动连接数归零。
- 悬浮 / 收回恢复原位置，独立页小标题右键可用；从主页关闭整组会连同该独立页关闭，活动连接数归零，浏览器未记录警告或错误。实际布局见[三窗格截图](design/screenshots/terminal-nested-split.png)。
- 前端自动测试覆盖嵌套三屏矩形、跨组移动、局部比例调整、关闭后树折叠、重连 ID 替换、独立显示时的组归属和窄容器边界，以及排除桌面 / 独立页 / 失效分屏目标。

## 调研依据

- [PuTTY 官方 FAQ](https://www.chiark.greenend.org.uk/~sgtatham/putty/faq.html)：默认选中复制、右键粘贴，Ctrl+C 发送远端控制字符，也可改为菜单式操作。
- [Windows Terminal 交互设置](https://learn.microsoft.com/en-us/windows/terminal/customize-settings/interaction)：右键复制 / 粘贴与上下文菜单配置。
- [xterm Terminal API](https://xtermjs.org/docs/api/terminal/classes/terminal/)：菜单使用公开的选择、粘贴、输入、字号和主题接口；切换所属浏览器窗口后再次 `open`。
