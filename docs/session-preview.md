# 服务器卡片的最后画面

## 当前交付

收藏夹与目录卡片右侧预留 88 × 88 px 的圆角正方形画面区，圆角 10 px。卡片固定宽 280 px，常规高度 114 px：左侧紧凑排列标题、地址、分组和连接按钮，右侧预览跨资料与操作两行，避免上下堆叠造成空白。收藏星标绝对定位在画面区右上角并与画面重叠，不参与正常布局、不占左侧操作栏，也不改变预览尺寸。卡片继续按容器宽度自动换行，窄容器中的连接按钮可换行并撑高卡片。画面区为空时显示图标与“暂无画面”，不伪造远端屏幕。

`frontend/src/components/SessionPreview.vue` 已支持通过 props 展示会话帧、协议标签和运行标记；加载失败退回占位。`frontend/src/session-preview.ts` 已定义预览数据与选择规则，并以单元测试验证多会话优先级、停止回退和帧归属。当前已实现 SSH 终端视图，但还没有画面采集器或截图定时器；卡片帧接口尚未接入实际会话。

## 选择规则

1. 对同一台服务器，运行中的会话按 **VNC > RDP > SSH** 选择，网页入口不参与。
2. 同一协议存在多个运行会话时，选最近活动的会话；时间相同则按会话 ID 稳定选择。
3. 高优先级会话正在运行但尚无画面时，显示该协议的占位，不把 SSH 画面标成 RDP / VNC。只有同一个会话、同一个协议才能复用上一帧。
4. 高优先级会话停止、低优先级会话仍运行时，回退到后者；没有帧时显示占位。
5. 所有会话停止后保留最后显示的那一帧，并取消运行标记。若没有已选帧记录，可取已有停止会话中采集时间最新的一帧；历史帧不再按协议优先级重选。

帧记录包含 `sessionId`、`protocol`、`objectUrl`、`capturedAt`。会话记录包含 `id`、`protocol`、`state`、`lastActivityAt` 与可选帧。预览协议类型独立于已启用连接器，预留 `vnc` 不代表当前应用已支持 VNC 连接。

## N 秒更新的后续接入

初始周期为 5 秒，代码中用 `DEFAULT_PREVIEW_INTERVAL_MS` 留出统一默认值；后续接入采集器时把 N 作为可配置项。运行中的被选会话首次有可用画面时采一帧，然后最多每 N 秒更新一次；停止后冻结最后一帧。该默认值是接入约定，目前不会产生实际定时采集。

由页面级预览管理器按服务器调度，一台服务器的收藏卡和目录卡共享结果，避免各组件重复截图。只对可见卡片及当前选中的运行会话采样；页面隐藏时暂停采样，恢复后取最新画面，不补拍隐藏期间的历史。采集进行中不叠加任务，版本变化后丢弃旧会话返回的帧，不让慢任务覆盖更高优先级的新画面。

每台服务器只留一个已选缩略图和一次进行中的替换，不累积截图历史。使用缩略图 Blob / object URL，替换解码并切换完成后释放旧 URL；服务器删除、退出或页面关闭时释放资源。缩略图仅保存在本页内存，不写入 localStorage、IndexedDB、配置导出或普通日志。

## 各协议的能力边界

连接由本地后端建立或启动，前端只发送 WS 连接请求和处理显示、输入。SSH 由后端 `ssh2` 建连；RDP 由后端启动 `mstsc.exe`，再由该客户端连接服务器；后续 VNC 由后端建立远程连接并用 WS 转发给浏览器。SSH / 浏览器 VNC 的缩略图优先复用前端现有画面，不为预览额外创建远端连接。

| 协议 | 画面来源与实施顺序 |
| --- | --- |
| SSH | 先接入真实网页终端，再由其视图提供缩略图采集器，核验实际 xterm.js 渲染器的采集方式。显示最新终端屏幕；用户向上翻阅不把旧历史当作最新屏幕，不复制全量输出，也不为截图创建额外终端。|
| RDP | 当前方案启动本机 `mstsc.exe`，浏览器没有该窗口的画面源。本机客户端被确认仍在运行时可作为 RDP 候选并优先于 SSH，但画面能力仍为空、显示占位；客户端启动结果不能冒充远端连接成功或已经采集到画面。需后续本机窗口采集或提供画面的连接器支持。|
| VNC | 后续实现浏览器 VNC 连接器时，由其远程帧缓冲或画布提供缩略图；本次只预留显示与优先级类型，不新增 VNC 启动入口。|

业务通信仍遵循纯 WS 约定。浏览器已有画面在本地缩小，不新增截图 REST API，不把完整 SSH 输出或未经缩小的高频桌面帧广播到目录订阅中。终端自身的解析、ACK 与背压独立于预览周期，截图失败或节流不得阻塞终端输入输出。

## 已做验证

`pnpm build` 包含类型检查；`pnpm test` 的 9 个用例覆盖协议优先级、高优先级暂无帧、帧归属、旧帧回退、同协议多会话和停止后保留。浏览器已检查实际卡片为 280 px，预览为 88 × 88 px、圆角 10 px；390 px 窄屏下预览仍在卡片内，页面无横向溢出。这些检查不包含真实终端截图、RDP 采集或 VNC 连接。
