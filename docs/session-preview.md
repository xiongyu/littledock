# 服务器卡片的最后画面

## 当前交付

收藏夹与目录卡片右侧预留 88 × 88 px 的圆角正方形画面区，圆角 10 px。卡片固定宽 280 px，常规高度 114 px：左侧紧凑排列标题、地址、分组和连接按钮，右侧预览跨资料与操作两行，避免上下堆叠造成空白。收藏星标绝对定位在画面区右上角并与画面重叠，不参与正常布局、不占左侧操作栏，也不改变预览尺寸。卡片继续按容器宽度自动换行，窄容器中的连接按钮可换行并撑高卡片。画面区为空时显示图标与“暂无画面”，不伪造远端屏幕。

`SessionPreview.vue` 展示会话帧、协议标签和运行标记；加载失败退回占位。`session-preview.ts` 定义预览选择规则，`session-previews.ts` 统一管理图片生命周期。网页 RDP / VNC 已接入真实客户端画布采样；SSH 当前只提供运行状态，还没有截图采集器；系统 mstsc 不提供状态或画面。

## 选择规则

1. 对同一台服务器，运行中的会话按 **VNC > RDP > SSH** 选择，网页入口不参与。
2. 同一协议存在多个运行会话时，选最近活动的会话；时间相同则按会话 ID 稳定选择。
3. 高优先级会话正在运行但尚无画面时，显示该协议的占位，不把 SSH 画面标成 RDP / VNC。只有同一个会话、同一个协议才能复用上一帧。
4. 高优先级会话停止、低优先级会话仍运行时，回退到后者；没有帧时显示占位。
5. 所有会话停止后保留最后显示的那一帧，并取消运行标记。若没有已选帧记录，可取已有停止会话中采集时间最新的一帧；历史帧不再按协议优先级重选。

帧记录包含 `sessionId`、`protocol`、`objectUrl`、`capturedAt`。会话记录包含 `id`、`protocol`、`state`、`lastActivityAt` 与可选帧。最近活动时间在连接就绪、选择标签和提升悬浮窗口时更新。

## 周期与内存

`DEFAULT_PREVIEW_INTERVAL_MS` 为 5 秒，目前没有单独的周期设置。每个运行网页桌面就绪时尝试采样，随后每 5 秒采样一次；后台页面暂停采样，重新可见时取最新帧，不重放隐藏期间的历史。非活动标签继续解码，因此回到目录仍可更新预览。

采集器属于桌面会话，不属于卡片，一台服务器的收藏卡和目录卡共享结果。最多 4 个网页桌面分别保留一帧，供优先级变化时立即切换。每次异步采样完成前不再发起另一次，已关闭会话的迟到帧直接丢弃。缩略图最长边 240px、JPEG 质量 0.72、单图最多 128 KiB；临时完整 Guacamole 画布在缩小后释放。

每台服务器另保留最后显示帧的引用；最多保留最近 100 台已停止服务器的最后画面，不累积截图历史。使用 Blob / object URL，视图切换后释放不再被引用的 URL；服务器删除、过限淘汰及页面关闭时释放。仅保存在本页内存，不写入 localStorage、IndexedDB、配置导出或日志；刷新页面不保留缩略图。

## 各协议的能力边界

连接由本地后端建立或启动，前端只发送 WS 连接请求和处理显示、输入。SSH 使用 `ssh2`；网页 RDP 插件调用本机 FreeRDP 组件；VNC 由 Node 建立 TCP 连接并完成认证。缩略图复用当前画面，不为预览另建远端连接。

| 协议 | 画面来源与实施顺序 |
| --- | --- |
| SSH | 先接入真实网页终端，再由其视图提供缩略图采集器，核验实际 xterm.js 渲染器的采集方式。显示最新终端屏幕；用户向上翻阅不把旧历史当作最新屏幕，不复制全量输出，也不为截图创建额外终端。|
| RDP | 网页客户端通过 `Guacamole.Display.flatten()` 提供当前画面。原生 mstsc 无画面源，不从启动结果推断远端状态，也不参与网页运行会话排序。|
| VNC | 复用 noVNC 画布；完成 ServerInit 后报告运行状态，解码出的画面用于缩略图。|

业务通信仍遵循纯 WS 约定。浏览器已有画面在本地缩小，不新增截图 REST API，不把完整 SSH 输出或未经缩小的高频桌面帧广播到目录订阅中。终端自身的解析、ACK 与背压独立于预览周期，截图失败或节流不得阻塞终端输入输出。

## 已做验证

新增 ADB / WDB 使用真实 PNG 或视频帧采集缩略图，选择优先级为 ADB / WDB > VNC > RDP > SSH / Local；同优先级按活动时间选择。Local 与 SSH 一样保留「暂无画面」占位，不把终端输出伪装成截图。采集、隐藏暂停、停止保留和内存释放仍使用现有规则。

选择规则有 9 个单元测试。2026-10-25 浏览器用本机模拟 RDP / VNC 流验证真实画布缩略图、运行标记、切换与停止保留；390px 窄屏无横向溢出。截图仍为 88px 圆角正方形。详见[网页桌面验证范围](embedded-desktops.md)，不包含真实远端登录或容量压测。
