# 通用插件框架实施记录

## 2026-10-29：共享和独占 Worker

主线程入口与 Cordis 业务装配分离；内置及默认外部插件运行在共享 Worker，声明独占的插件从导入开始使用专用 Worker。补齐异步宿主接口、带身份的 interop 转发、取消、租约、消息额度、故障撤销及候选线程热切换。任务管理器与系统优化各占一个 Worker，其余现有插件使用默认共享线程，插件详情显示实际位置。现有插件直接改用当前 SDK，移除原始 Context、同步租约及 Cordis 工厂注入。任务管理器通过异步宿主接口鉴权、获取凭据、核对指纹，并在协调端原子预留连接额度；具体边界、生命周期与测试入口见 [执行模型](plugin-workers.md)，实际批次见 README。

## 2026-10-28：公开控件与跨插件界面扩展

已完成菜单、标签页、面板、操作栏的声明 / 注册 / 实例自动回收；默认公开、可手动非公开，插件 ID + 控件名和版本作为契约。声明含用途及字段说明，生成静态表与 JSON，供其他开发者或 AI 离线查阅。任务管理器进程菜单和详情标签，以及终端、AI 终端、SSH 文件与工作区标签菜单已接入。两个独立示例验证了宿主与第三方互相扩展、来源标记、错误隔离、禁用 / 卸载；没有实现真实调试器。实现范围、测试批次与截图见 [界面扩展](plugin-ui-extensions.md)，公开清单见 [静态目录](plugin-ui-catalog.md)。

开始日期：2026-10-28。通用扩展首版已完成，实际公共接口见 [SDK](plugin-sdk.md)。对应设计：[平台](plugin-platform.md)、[总览与配置](plugin-settings.md)、[审查](plugin-framework-audit.md)。历史内置服务仍保留固定槽兼容装配；不宣称所有旧内置服务已拆成可独立卸载的包。

## 与系统优化工具分离

[系统优化工具](system-optimizer.md)独立保留需求、开源参考、UI 和系统动作方案。本轮先完成框架和隔离示例验收，再在 `plugins/system-optimizer/` 实现工具首版，没有在宿主中加入系统优化业务。
