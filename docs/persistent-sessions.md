# 后台会话与浏览器恢复

## 当前行为

SSH、本地终端、内置网页 RDP / VNC / ADB / WDB 由本机后端持有。刷新网页、关闭浏览器和显示通道断开只移除浏览器视图；同一浏览器配置重新打开工作台、完成必要的解锁后，读取后端清单并接回原连接，不重新登录目标。每个普通会话只允许一个输入和显示附件，新页面接管后旧页面提示连接已在另一页打开，不自动争抢。

明确关闭窗格结束该连接，关闭主标签结束整组。远端退出、认证失效、提供者停止或 WebNav 后端退出会释放资源。这里的持久是跨浏览器生命周期的后台运行，**不承诺跨后端重启、电脑重启或远端断线恢复原 Shell**。输出历史是独立的磁盘文本记录，不用于复活 Shell。托盘重启/退出仍会结束宿主持有的连接。

归属沿用后端 HttpOnly Cookie：同一浏览器配置关掉再开可以恢复；换浏览器、清理 Cookie 或授权过期不能冒领原连接。运行中的资源与工作区布局只在后端内存，不写入目录备份、配置同步或浏览器存储。全局最多八个连接，其中桌面和设备最多四个；没有网页观看的会话继续计入预算及插件资源占用。

## 工作区与鉴权

业务 WS 提供 `workspace.snapshot`、`workspace.save` 和三个协议族的 `attachTicket`。快照按 owner 过滤，包含运行会话和布局版本；保存只允许有界的会话引用、标签顺序、分屏树/比例、当前标签、悬浮和最小化标记，使用操作 ID 去重及 expectedRevision 检查。至多八组、二十四个布局节点、八层深度、六十四个 owner 的布局，不包含终端输出和秘密。

票据随机、单次、三十秒有效，必须已解锁且归属匹配；新票据使旧票据失效。恢复只绑定已有资源，不能指定目标或凭据。旧显示 WS 的输入和 ACK 被所属 socket 校验拒绝。超时不自动重放输入或连接启动。插件等待切换/整包更新等待期间允许读已有清单、重新绑定和明确关闭已有资源。

SSH 独立显示窗口仍依赖主页的 Vue 实例；主页离开时关闭这些显示窗口，后端 SSH 继续运行。重新打开主页后恢复到主工作区，不自动创建弹窗。布局保存是短时合并的异步写入，pagehide 会尝试提交最后一次变更；浏览器被强制杀死时以最后成功保存的布局为准，后端存活连接仍可恢复。

## 终端

后端使用 headless xterm 持有当前屏幕与两千行滚动历史，并独立解析远端字节；终端设备查询只由此解析器应答。远端读取依赖后端解析完成，不依赖网页是否存在。原始输出解析队列保持一 MiB 上限。

新的网页先接收 `terminal.snapshot` 尺寸及有界的序列化当前状态，再连续接收新输出；状态生成和字节解析串行，避免快照边界重复/遗漏。恢复不重放键盘输入，不向运行中的旧 xterm 灌入历史库。网页的两千行滚动历史、二百五十六 KiB 在途和解析回调 ACK 保持独立；积压超过八 MiB 或三十秒不确认仅移除慢视图，后端继续解析。远端正常退出时，已解析的最后输出先按浏览器 ACK 排空，再结束显示；显式关闭立即释放。

显示通道意外断开后保留页面输出，提示“按 Enter 恢复原会话”；远端已结束则显式重连创建新会话。Enter 仍仅由获得焦点的终端响应，过滤修饰键、重复键及输入法确认。

## 桌面和设备

FreeRDP 新增带代次的 viewer 控制和确认。无网页时暂停编码/显示发送、释放已按下的键鼠并清空旧 ACK，但继续维护原 RDP 连接和最新像素缓冲；重新附着后发送尺寸、完整画面和当前光标。Node 丢弃旧代次显示数据，旧 ACK 不得确认新画面。没有截图队列或后台录像。原生组件和随附压缩包必须一起更新。

VNC 在后端保留已认证的 RFB 连接，并为每个网页重建本地握手。当前协商 raw、DesktopSize 和光标这三种无状态编码，固定 32 位真彩格式；新页面请求完整画面，旧画面按代次排空。它没有 Tight/ZRLE 压缩，带宽可能高于旧直通链路；不支持通过浏览器请求远端改分辨率，仍能接收服务器 DesktopSize 变更。当前上限 4096 × 2160，未验证高分辨率/多画面长期吞吐。

ADB / WDB 无网页时释放控制、暂停提交视频；重新绑定重置 ACK、补设备信息并请求可解码起点，不自动恢复控制权。仍按原安全规则在全局锁定后关闭设备连接。普通 SSH / 本地终端及已认证桌面的锁定策略不变，锁定期间禁止新建和重新绑定。

旧第三方提供者不自动获得恢复能力：桌面流须声明 `viewerVersion: 1` 并实现 `setViewer`，设备流须声明 `viewerVersion: 1` 并处理隐藏时释放控制和新观看时的解码起点。未声明者在显示断开时沿用原有释放规则。替换整个 sessions/desktops 服务时，清单、票据和计数接口为可选扩展，旧实现不支持时明确报不可用；不能伪造恢复成功或零连接。

## 托盘

悬停提示及右键菜单显示实际已建立的 SSH / 网页 RDP 数量；有 VNC、本地终端、ADB、WDB 时追加相应数量，全部为零显示“暂无运行”。SSH 包含仍在运行的 AI SSH，未建立的认证请求不计入运行数；系统 mstsc 与独立监控 SSH 不在此会话服务计数范围。状态未取得或替换服务不提供计数时显示“正在读取连接状态”。

工作进程每秒读取一次计数，仅变化时经带启动 nonce 的 IPC 更新 supervisor；不会向托盘发送服务器名、地址、输出或秘密。重启和进程退出清空旧计数；不查询或干预用户独立启动的 mstsc。

## 2026-10-28 验证

共享类型、前后端生产构建通过，Windows 原生 RDP 重新编译并生成随附压缩包。最终会话/设备/桌面/托盘批次 27 项通过，前端 64 项通过；另有 WinForms 实际控件回归、插件等待/切换、AI、SFTP、历史和原生 RDP 测试。测试使用隔离应用配置和数据目录，没有重启或更改日常运行实例。

在隔离目录、本机模拟 SSH / VNC 和真实 FreeRDP 连接本机测试 RDP 服务下，Edge 验证了刷新与完全退出浏览器再打开：两个 SSH、RDP、VNC 保持原会话 ID、原连接次数和 SSH PTY，后台输出、分屏、输入、完整画面、390px 和显式关闭释放均检查。原生 FreeRDP 额外验证无网页超过三十一秒后可恢复同一连接。ADB / WDB 恢复仅通过模拟提供者验证，没有此次真实设备验收。
