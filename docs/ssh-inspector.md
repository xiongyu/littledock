# SSH 系统信息与文件栏

SSH 工作区左侧显示系统信息，终端下方显示文件栏。系统信息跟随当前选中的 SSH 窗格，文件栏通过编号选择对应终端并跟随目录；顶部 CPU、文件夹图标分别开关，两栏标题上的关闭按钮作用相同。RDP / VNC 不显示这些面板。系统信息栏右边界可左右拖动，默认 260px、范围 200–420px，双击恢复默认，也支持方向键调整；窄窗口受可用宽度约束。文件栏上边界可上下拖动。调宽不重新挂载终端、不重连，字号不变。

系统信息包含主机名、系统版本、运行时间、CPU 使用率和核心数、内存、磁盘。Linux 另显示负载，CPU 首次需两次采样才显示使用率。面板可见且 SSH 就绪时每 5 秒读取一次；关闭面板即停止轮询。失败显示说明并停止自动重试，可手动刷新，不弹出打断终端的对话框。

界面采用主机摘要、运行时间、对齐的 CPU / 内存指标与独立磁盘容量条；页脚显示实际采样时间。颜色沿用皮肤变量，内存用独立语义色区分；不生成虚构的历史曲线。设计参考与生成提示词见[系统信息栏设计](design/system-inspector-prompt.md)。

文件栏通过 SFTP 读取远端主目录，可进入子目录、返回上级、输入路径、刷新和翻页，显示名称、大小、修改时间、权限与用户 / 组。支持文件右键、编辑、上传下载、ZIP、编号定位与目录跟随，详情见[SSH 文件管理](ssh-files.md)。权限 / 用户组采用 SFTP 返回的数字信息；Windows 服务端可能返回有限的 POSIX 属性。

## 插件与通信

`sshInspector` 是独立 Cordis 服务，依赖 `sessions` 和 `credentials`。业务 WS 提供：

| 方法 | 参数 | 返回 |
| --- | --- | --- |
| `ssh.system` | `sessionId` | `SshSystemInfo` |
| `ssh.files` | `sessionId`、`path`（默认 `.`）、`offset`（默认 0）、`refresh`（可选） | `SshFilePage` |

DTO 位于 `shared/src/ssh-inspector.ts`。每次请求校验主密码解锁、会话归属、SSH 就绪状态，异步读取完成后再次校验。服务端提供固定的 Linux / Windows 只读探测命令，前端没有任意命令参数。系统信息使用原 SSH 连接的独立 exec 通道，文件使用独立 SFTP 通道，不经交互 Shell，不混入输入或输出历史。

支持 Linux 的 `/proc` 与 `df`，Windows 的 PowerShell / CIM。命令或 SFTP 不可用时显示实际失败状态，不能用本机信息或假数据替代远端信息。

Windows 探测同时将 `[Console]::OutputEncoding` 与 `$OutputEncoding` 设为无 BOM UTF-8，后端合并有界字节块后按 UTF-8 解码。`-EncodedCommand` 的 UTF-16LE 只影响命令输入，不能保证输出编码；若不显式设置，中文系统名可能被默认 OEM / GBK 编码破坏。本设置仅作用于独立探测进程，不修改交互终端或远端全局代码页。

## 边界与生命周期

- 同一 SSH 连接每类查询最多一个在途请求；系统快照缓存 3 秒。探测通道 8 秒超时，stdout / stderr 合计上限 64 KiB。
- 每次目录读取最多保留 2,000 条，超限明确显示；每页 100 条，每个 SSH 连接仅缓存一个目录，20 秒过期，手动刷新重新读取。路径上限 4,096 字符，拒绝控制字符；路径只作为 SFTP 参数，不拼接命令。
- 通道结束、失败、超时或 SSH 关闭均释放临时通道和定时器。缓存用 SSH client 的弱引用绑定，不进入数据库或日志。
- 前端仅保留当前系统快照和当前文件页；切换终端、关闭面板、锁定或业务断线时清理并丢弃迟到响应。不保存到浏览器持久存储。导航宽度、系统信息栏宽度、各面板开关和文件栏高度作为纯布局偏好保存在浏览器。
