## 初稿

Use case: ui-mockup.
Asset type: high fidelity desktop app screen, visual blueprint for implementing real HTML for WebNav.
Primary request: Design a refined, spacious, modern Chinese-language local server navigation workspace. Calm low saturation colors and excellent readability for long use. This is a daily utility homepage, not a marketing landing page.
Composition: one finished full-bleed desktop screen at 1600x1000 aspect ratio. Crisp straight-on screenshot, no monitor bezel, no perspective, no explanatory annotations. Left sidebar 232px. Topbar 72px. Spacious main content with 44px horizontal padding. Main workspace centered on server groups, favorites and direct SSH/RDP entry. No huge hero or graphs.
Color palette: very light mist gray-green background #F3F5F2, slightly darker sidebar #E9EEE8, off-white surfaces #FAFCF9, deep graphite text #25342C, muted forest-green accent #426653, pale sage selection #DCE7DB. Very restrained borders #DCE2DB. No purple, no neon, no saturated blue, no glowing effects. Entire screen is light theme with no large dark blocks.
Typography: modern clean sans serif, precise Chinese UI glyphs, large but functional heading, monospaced IPs, strong spacing rhythm. Quiet premium software quality. Soft 12px cards and 8px buttons, subtle minimal shadows.
