# SSH 文件管理与目录跟随

文件栏使用现有 SSH 连接上的 SFTP 通道，业务操作全部通过 WS。它可以关闭，再从顶部文件夹图标打开；不新建 SSH 登录、不向交互终端注入命令。

## 编号定位

分屏小标题显示 `1 / 2 / 3 …`，文件栏标题提供对应数字按钮。点数字立即定位到该终端的当前目录，并继续跟随它；对应窗格同时亮起边框和编号，轻微放大后在 900ms 内淡出，重复点击可重播。动画不调整分屏尺寸或终端字号；系统减少动态效果偏好下仅短暂淡出。不会因为点击另一个终端输入就换掉当前文件目录。组内默认选择最早创建的 SSH。成员变化后按创建顺序重新编号，标题与按钮始终一致。

双击不是必要条件：点击文件夹、上级目录或输入路径进入目录，都会暂停跟随。数字按钮与链条按钮可重新定位并恢复跟随。切换来源时清除上一来源的列表和迟到请求；关闭文件栏停止轮询。

后端从输出识别 OSC 7、OSC 1337 CurrentDir，以及常见 Linux `user@host:/path$`、Windows `user@host C:\path>` / PowerShell 提示符。只保存最后目录与修订号，不记录命令输入，也不靠猜测 `cd` 参数计算路径。页面每 2 秒查询所选终端报告的目录，并用 SFTP 规范化后读取。没有目录报告、也没有可识别路径的自定义提示符不能自动定位，保留手动浏览；显式定位时给出说明。该方式不是任意 Shell / TUI 的工作目录探测。

## 菜单、传输与编辑

标题代码图标、文件夹/空白处右键另提供[远程 VS Code](remote-editor.md)：在目标服务器运行完整浏览器编辑器，经 SSH 转发打开。它与“本地 VS Code（同步保存）”区分，前者直接编辑远端目录，后者下载副本到本机再回传。

| 对象 | 操作 |
| --- | --- |
| 普通文件 | 内置编辑器、VS Code、记事本、下载、重命名、复制路径 / 名称、ZIP 压缩、属性 / 权限、删除；ZIP 文件另有解压 |
| 文件夹 | 打开、上传到此目录、重命名、复制路径 / 名称、ZIP 压缩、属性 / 权限、递归删除 |
| 列表空白处 | 上传文件 / 文件夹、新建文件 / 文件夹、复制当前路径、刷新 |

右键使用专用菜单，选中行支持 F2 重命名、Delete 删除、Enter 打开、菜单键。删除和同名覆盖需要确认；取消不会自动重试写入。拖入文件时整块文件栏显示上传样式和完整目标路径；停在文件夹行上以上传到该文件夹为准，停在空白区域以当前目录为准。释放后上传，支持目录层级和空目录；浏览器的文件夹选择器通常不提供空目录，空目录保留能力针对拖入目录。

传输使用 128 KiB 顺序数据块，每块完成后发送下一块，避免整个文件进入浏览器内存。单文件上限 512 MiB，目录拖入上限 2,000 项 / 32 层；下载优先流式写入浏览器选择的本地文件，不支持此接口的浏览器回退到最多 64 MiB 的 Blob 下载。取消上传会关闭句柄、删除尚未提交的临时文件；之前已完成的文件和创建的目录保留。连接中断时临时清理只能尽力完成，远端可能留下 `.webnav-*` 临时项。

业务 WS 的 128 KiB 数据块与远端 SFTP 包大小分开：`RemoteFs.write` 将数据按最多 32 KiB 顺序写入，并保留准确文件偏移，兼容拒绝大 WRITE 请求的 Windows OpenSSH。收到失败后立即停止，不自动重放已写入部分；该处理同时覆盖普通上传、编辑保存、归档与编辑器安装包。测试服务模拟超过 32 KiB 返回状态 4，验证文件完整性、非零偏移和失败后停止。

内置编辑使用按需加载的 CodeMirror 6，最多同时打开 4 个浮动编辑器；支持拖动、缩放、最大化、语法高亮、查找 / 替换与 Ctrl+S。上限 512 KiB 文本，保留 UTF-8、带 BOM 的 UTF-16、GB18030 和换行符，二进制不强行显示。关闭未保存文件和离开页面会提醒；可另存 UTF-8 本地副本。文件正文不写入浏览器持久存储、目录备份或日志。

本地编辑目前支持 Windows 已安装的 VS Code 与系统记事本。后端下载到 `%TEMP%/webnav-edit-*/`，用固定可执行文件及独立参数打开，不接受任意命令。监视目录内保存事件，兼容编辑器写临时文件后替换的保存方式；700ms 合并事件，文件上限 16 MiB。关闭编辑器进程不等于关闭文件，因此同步持续到用户点“停止”、SSH 关闭、主密码锁定或服务停止。正常同步完成的副本可清理；未同步修改保留，并可复制本地路径自行保存。

保存采用内容哈希检查，远端变化时暂停回传并保留本地修改。内置编辑器需要重新打开、合并内容；外部编辑可以明确确认“覆盖回传”。写入先落到同目录临时文件，完成后重命名；支持 OpenSSH POSIX rename 时原子替换，否则使用备份与回滚。SFTP 没有跨客户端比较并交换接口，不能保证检查与替换之间绝无其他客户端写入。

## ZIP 与资源边界

ZIP 压缩 / 解压由本机后端通过 SFTP 流式处理，不依赖远端安装压缩软件，不拼接 Shell 命令。压缩生成 `<名称>.zip`，解压生成 `<名称>-extracted/`，已有目标不会直接覆盖。解压暂存 ZIP 到本机临时目录，结束清理；拒绝绝对路径、上级路径跳转、重复路径及符号链接，最多 2,000 项 / 32 层 / 512 MiB 解压内容。目前没有 TAR、RAR、7z 或带密码压缩包支持。

`sshFiles` 是 Cordis 服务，依赖 `sessions`、`credentials`、`sshInspector`。每次操作检查页面归属、解锁和 SSH 状态；写后使目录缓存失效。文件句柄、监听器、通道和临时目录有明确释放路径。最多 12 个 SFTP 通道、8 个文件传输、4 个压缩或本地编辑任务；传输空闲 3 分钟回收，归档 10 分钟超时，状态最多 32 项。普通操作 25 秒超时；超时不代表写入没有完成，前端不自动重放。额度是实现边界，不代表完成了最大容量或吞吐压测。

## 验证（2026-10-26）

本机模拟 SSH / SFTP 覆盖：中文编码与换行、路径校验、归属和锁定、保存冲突、暂存文件清理、分块上传下载及空文件、取消、递归操作、ZIP 目录往返与失败回收、本地文件保存监视与冲突暂停 / 确认覆盖。外部编辑器单元测试替换启动器，未自动打开真实 VS Code / 记事本窗口。目录拖入遍历测试覆盖多批次读取、空目录、中文路径、深度与数量限制。

浏览器使用独立数据库和模拟目标验证文件 / 文件夹 / 空白处菜单、中文文本 Ctrl+S 保存、浮动编辑器拖动、通过选择器上传嵌套目录、ZIP 压缩及解压。三个分屏保持一个主标签，分别点编号定位到各自目录；手动浏览暂停、再次定位恢复、后续 `cd` 自动跟随均通过。390px 视口无整页横向溢出。编号定位高亮实测仅作用于对应窗格，900ms 后移除，连续点击重播；两个窗格始终为 507×398px，会话 ID 不变。浏览器工具不提供原生文件拖入事件，拖入覆盖层尚需手工鼠标验收；不能把文件选择器验证当成原生拖入已通过。没有修改用户真实远端文件，也没有验证所有 SFTP 服务器兼容性。
