# 本地终端、安卓 ADB 与 WDB

三个内置插件随应用构建，遵循 [插件规范](plugins.md)，在插件中心显示本地清单、图标与使用说明。管理中心编辑服务器时，可添加「本地终端」「安卓 ADB」「WDB」入口；使用现有标签页、悬浮窗口和关闭回收流程。

| 插件 | 服务 / 连接器 | 分类 | 入口 |
| --- | --- | --- | --- |
| `builtin.local` | `service:local` / `connector:local` | 终端 | `backend/plugins/builtin.local/` |
| `builtin.adb` | `service:adb` / `connector:adb` | 桌面 | `backend/plugins/builtin.adb/` |
| `builtin.wdb` | `service:wdb` / `connector:wdb` | 桌面 | `backend/plugins/builtin.wdb/` |

内置清单由宿主自动加入插件列表，不需要把本机源码目录发布到市场索引。功能替换默认在线生效，相关终端或设备连接使用中时等待结束后自动切换；无法在线替换时明确提示待重启。第三方可按相同服务与连接器契约替换实现，原有连接仍通过提供者选择决定使用哪个插件。

## 本地终端

在**运行 WebNav 后端的电脑**打开交互式 Shell。Windows 自动选择 Windows PowerShell，macOS 自动选择 Zsh，Linux 自动选择 Bash；Unix 默认 Shell 不存在时回退 `/bin/sh`。入口也可明确选择 PowerShell 7、CMD、Bash、Zsh 或 POSIX Shell；未安装或不适合当前系统时提示失败。

工作目录留空使用当前用户主目录，也可填写已存在的绝对路径。选择本地入口时空服务器地址自动填 `127.0.0.1`，地址仅用于目录资料，不发起 SSH。目录格式仍保留 `port: 1` 占位，表单不显示端口。插件不接受任意启动命令或自定义可执行文件路径；打开后用户通过终端正常输入本机命令。

`node-pty` 在每个会话的独立 Node 辅助进程中运行；Windows 使用 ConPTY。终端复用 xterm、UTF-8 字节流、尺寸调整、累计解析 ACK、256 KiB 网页在途和 1 MiB 后端解析队列上限。明确关闭标签或插件释放时回收本次 PTY 和辅助进程；终端 WS 断开只移除视图，刷新和关闭浏览器再打开可接回原 PTY。仅切换标签或悬浮状态不会重新连接。

本地输出历史默认关闭，可在入口中明确开启；开启后使用同一独立只读历史对话框和后端留存策略。不记录输入。实时历史仍是 xterm 默认 2,000 行。SSH 的 SFTP、系统信息、远程编辑器、嵌套分屏与独立页未扩展到本地终端。

## 安卓 ADB

先安装 Android Platform Tools。插件依次检查 `WEBNAV_ADB_PATH`（绝对路径）、`ANDROID_HOME` / `ANDROID_SDK_ROOT` 下的 `platform-tools`、`PATH`。更改环境变量后重启 WebNav。手机需开启 USB 调试并在手机上允许当前电脑；部分系统还要求「USB 调试（安全设置）」才能注入触摸与按键。

USB 入口可以读取本机设备并选择序列号；留空只在恰好一台设备已授权时自动选择，不替用户决定多设备目标。网络入口使用服务器地址与端口（默认 5555）；Android 无线调试需要先在本机完成 `adb pair`，插件不会自动打开无线调试。

### 增强控制（默认）

随插件分发官方 **scrcpy server 3.3.4**。server 是 APK 格式的 Java 包，以 `.jar` 保存；每次连接自动推送到手机 `/data/local/tmp/` 下随机命名的会话文件，通过 `app_process` 启动，不安装普通桌面应用。来源、许可证和校验值见 [server 说明](../backend/plugins/builtin.adb/scrcpy/README.md)。离线使用不必再下载 server。

实现参考已有 scrcpy 封装的推送、双通道和输入协议流程，以 TypeScript 适配当前 WebNav 生命周期。版本与 SHA-256 固定；默认 H.264、最长边 1280、最高 60 FPS、8 Mbps，入口可调整帧率、大小与码率。选择的 FPS 是编码上限；工具栏显示浏览器实际呈现 FPS，静止画面可降至 0，不把配置值当作实测帧率。

一条本机临时 ADB 转发承载视频和控制两个 socket。视频使用 Annex-B、12 字节帧头，处理任意 TCP 分块、编码参数、关键帧与旋转后的尺寸变化。浏览器用固定 JMuxer 2.1.0 转为 MSE；恢复可见或重置解码器后请求新配置与关键帧，不能从丢失参考帧的中间继续解码。

支持实时触摸按下 / 拖动 / 松开、滚轮、物理键盘、安卓返回 / 主页 / 最近任务 / 唤醒，以及手动粘贴中文与其他 UTF-8 文字。粘贴会设置手机剪贴板并粘贴到当前输入框；不读取或自动同步手机剪贴板。首次仅查看，需点击「仅查看」开启控制；焦点离开设备区域、页面隐藏或关闭时释放输入并停止控制。工具栏与文字框之间切换焦点释放已按下的键，保持控制模式。

关闭时回收本次 scrcpy 进程、两个 socket、生成的 server 文件和对应临时转发，不执行 `adb kill-server`，不删除其他转发，不断开其他 ADB 客户端。启动取消和异常也走同一幂等清理。

### 基础控制

可选择 ADB PNG 截图模式，1–5 FPS 上限。支持点击、滑动、导航键和 ASCII 文本；通过独立参数调用 ADB，文本按 Android shell 规则引用。它是低频兼容模式，不提供 scrcpy 的连续视频或中文粘贴。失败不会自动切换模式。

## WDB

WDB 是独立的 Windows 被控端。WebNav 直接连接它的内置网页服务（默认端口 **27880**），不依赖 AxisAuto 的反向连接服务器，也不会修改该反向连接的地址或令牌。

被控端需运行**完整模式**，已初始化网页管理员，并允许所需的键鼠控制。用户名和密码是 WDB 网页管理员，与 Windows 登录和 AxisAuto 令牌独立。HTTPS 选项适用于目标提供受信任 TLS 证书的部署；当前 WDB 内置服务通常为 HTTP。

后端登录 `/api/login`，检查 `/api/status`，再连接 WDB 的 `/ws/control` 与 `/ws/video`。WDB 密码、登录 Cookie 和 CSRF 值只留在后端；浏览器获得 WebNav 自己的一次性设备绑定票据。密码通过 `catalog.replace.desktopPasswords` 与入口事务保存，使用现有凭据服务，不进入目录导出。

WDB 每次网页登录会替换之前的网页登录。插件初始只查看画面，用户开启控制后才发送物理扫描码、鼠标移动 / 按键 / 滚轮。F8 保留给 WDB，不向远端发送。被控端拒绝控制时显示原因并保持仅查看；不绕过 WDB 的输入所有权、物理释放确认或隔离状态。

「仅管理」模式会在连接时明确提示切换完整模式，不持续显示“正在连接”。没有首帧、认证失败、会话被替换、断线和视频过载均有明确失败状态，可以手动重连。WebNav 不自动修改被控端模式、输入设备或采集配置。

## 通道与资源边界

- 本地终端复用 `/ws/terminal`；ADB / WDB 每会话使用一个 `/ws/device`。业务 RPC 仍只走 `/ws`，没有新增 WebNav REST 业务接口。
- 设备票据随机、单次、30 秒有效且绑定创建者。Host、精确 Origin、Cookie、当前授权和所属会话均校验；重复或其他浏览器的绑定失败不能销毁原连接。
- ADB / WDB 与网页 RDP / VNC 合计最多 4 个画面，与所有终端合计最多 8 个连接。设备输入每秒最多 240 条、并行处理最多 16 条；输入不会在超时后自动重放。
- 设备二进制包前缀是 4 字节大端序号；最多两包等待累计 ACK，总在途 payload 最多 16 MiB，WS 写入缓冲最多 2 MiB，15 秒不确认移除视图。内置提供者支持后台保留；旧插件未声明 viewerVersion 1 时仍释放会话。
- scrcpy / WDB 待发送视频最多 4 MiB；scrcpy 暂停视频 socket 施加背压，无法保持有界时停止连接。浏览器待处理设备帧最多 20 MiB，编码配置最多 256 KiB，JMuxer 待追加 / 待封装数据最多 8 MiB。MSE 定期清理已播放内容，清理窗口使用固定版本内部字段；升级 JMuxer 需重新核验这些字段。
- 隐藏设备画面停止提交帧并释放输入，重新显示请求可解码起点。设备连接在全局锁定或授权失效后释放；已经建立的本地终端沿用 SSH 的锁定规则。
- 设备缩略图每 5 秒从真实 canvas / video 缩小采集，只在当前页面内存中保留；本地终端仍显示“暂无画面”，不伪造截图。

## 验证与边界

2026-10-26，Windows x64 / Node 24.16.0 / Edge：

类型检查与生产构建通过，完整测试后端 82 项、前端 42 项通过。浏览器还验证了 PowerShell / CMD 中文与命令输入、悬浮窗口、390px 设备工具栏和连接表单；测试进程、ADB 临时转发和 server 文件在关闭后回收。其他平台和长时容量不在此次验收内。

- 自动测试覆盖新类型与配置校验、本地真实 PTY 中文输出 / 调整尺寸 / 关闭、重复绑定不影响原会话、ADB 模拟截图背压与输入校验、WDB 模拟登录 / 控制 / 清理、设备归属与 ACK 额度 / 锁定、scrcpy 字节协议 / 任意分块 / 旋转尺寸 / 固定包校验。
- 使用用户授权的 USB 手机，增强模式收到 720 × 1280 H.264 视频，验证触摸点击、导航按键、Settings 搜索框内中文粘贴；动画期间浏览器实际输出明显高于基础截图频率。没有把 60 FPS 配置宣称为持续实测结果。
- 使用用户指定的 WDB 目标，完成管理员初始化、真实桌面显示和开启控制。原目标是「仅管理」模式，自动输入检测未能确认硬件释放；验证时临时使用完整模式 / SendInput，结束后恢复原模式与输入设置。其他用户必须依据自己的被控端状态配置，插件不代改。

尚未验证 Linux / macOS / Windows ARM64 实机、其他 Android 厂商及版本、无线配对、多设备长时间并发、长时内存和吞吐容量。当前不包含音频、录屏、文件传输、自动安装完整 ADB 工具链或 scrcpy HID / OTG。2026-10-28 增加跨浏览器关闭的[后台会话恢复](persistent-sessions.md)：设备脱离时释放输入，恢复后重置 ACK 并请求解码起点，控制默认关闭；此次恢复验证使用模拟提供者，不扩大既有真实设备验收范围。
