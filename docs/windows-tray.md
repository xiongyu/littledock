# Windows 托盘运行

[便携正式版](online-updates.md)使用包内 Node 和固定 `launch.mjs`，按安装记录选择当前版本。已有自启项会迁移到固定入口，保留数据路径和选项；未勾选时不创建。在线更新不改自启入口，移动安装目录后仍须重新登记位置。

远程编辑器的 `WEBNAV_EDITOR_ENABLED` 和 `WEBNAV_EDITOR_PACKAGE_DIR` 随启动配置传递并保留到自启；安装包默认留在本机数据目录，见[远程 VS Code](remote-editor.md)。

## 使用

开发运行 `npm run dev`（或 `pnpm dev`）。命令会检查启动结果，成功后返回；前后端留在后台，右下角出现 WebNav 托盘图标，没有主窗口。此时关闭启动终端不影响服务。首页为 `http://127.0.0.1:5173/`。

正式运行先 `pnpm build`，再 `npm start`（或 `pnpm start`），首页为 `http://127.0.0.1:3030/`。同一用户的应用配置目录只允许一个工作台实例，开发、正式和前台调试入口共用该限制。切换仓库目录、端口或 `WEBNAV_DATA_DIR` 后重复运行，也会复用已经启动的实例；要切换模式或数据库，先退出原实例。

**重复运行默认打开已有工作台的网页**，使用原实例实际运行的网址。原实例还在启动时先等待就绪，再打开一次；不新建后台服务、不替换原实例参数，也不打断已有 SSH / 桌面。若浏览器打开失败，命令显示可直接访问的网址，已有工作台继续运行。首次升级到此版本需先退出旧工作台，再启动一次，以加载新的实例管理逻辑。

右键菜单：

| 操作 | 行为 |
| --- | --- |
| 打开主页 | 用系统默认浏览器打开当前实例的主页；双击托盘图标也可打开 |
| 开机启动 | 勾选后在当前用户登录 Windows 时隐藏启动；取消勾选删除本应用自己的启动项，不需要管理员权限 |
| 重启 | 关闭本次托管的前后端，再以相同模式、端口、数据目录启动；数据库保留，网页连接需要重新建立 |
| 退出 | 关闭托盘和它托管的前后端，释放端口；不关闭已打开的浏览器或系统 mstsc 桌面 |

默认不开启开机启动。设置保存启动时使用的 Node 路径、仓库路径、开发/正式模式、端口、数据目录和网页 RDP 插件开关；不保存整个环境变量或凭据。若移动项目、Node 安装或数据目录，应取消旧启动项，再在新位置重新勾选。Windows 可能把图标收入右下角 `^` 的隐藏图标区。

菜单顶部与图标状态点显示启动中、运行中、重启或失败。启动失败保留托盘，可修复端口/依赖后选择重启。原实例处于失败状态时重复运行显示失败原因，不伪报网页已打开。旧版终端启动的服务仍占用端口时会明确提示，需先关闭旧启动终端。

图标悬停提示和右键菜单同时显示后台运行数，例如 `SSH 2 · RDP 1`；有其他内置连接时追加其数量，全部为零显示“暂无运行”。没有取得计数时显示“正在读取连接状态”，不把未知当成零。SSH 包含 AI SSH，RDP 仅计网页内嵌会话，不推测系统 mstsc 的远端状态。刷新/关闭浏览器不会把存活连接减掉，明确关闭连接后才更新，通常在一秒内。工作进程通过带启动 nonce 的 IPC 仅传汇总数，重启/退出清空旧计数；详情见[后台会话](persistent-sessions.md)。

## 生命周期与实现

- `scripts/dev.mjs` / `scripts/start.mjs`、console 命令与直接后端 main 入口统一使用 supervisor；Windows 默认隐藏启动，命令收到就绪结果后返回。前台模式等待自己启动的 supervisor 退出。
- supervisor 使用当前用户应用配置目录对应的 Windows 命名管道实现单实例，标识不包含所选数据库、工作目录、模式或端口。控制消息验证随机令牌，只支持查询、打开、重启和退出；不增加 HTTP 业务接口。
- 在构建开发资源、加载数据库及绑定业务端口前获取实例所有权。工作进程除内部环境标记外，还核对控制管道中的父进程与工作进程 PID，避免直接运行工作脚本绕过检查。
- 重复启动只重试实例发现；就绪后发送一次“打开主页”，打开结果未知也不循环重发。网址由持有实例的 supervisor 决定，不接受后启动者传入的网址。
- 服务子进程负责 Cordis 与开发 Vite；supervisor 通过进程 IPC 等待真实就绪，重启按先停后启顺序执行，重复重启请求合并。仅管理自己创建的服务进程。
- Windows 自带 PowerShell / .NET WinForms `NotifyIcon` 提供托盘，无 Electron、浏览器外壳或主窗口。菜单通过标准输入输出通知 supervisor；菜单线程不阻塞等待服务。
- 正常退出先通知服务释放 WS、SSH、历史库和 SQLite，超时只结束自己的工作进程。supervisor 异常结束后，工作进程因 IPC 断开执行清理，托盘因输入管道关闭退出。托盘意外结束也会停止服务。
- 开机启动使用当前用户 Startup 目录中的 `WebNav-<实例标识>.lnk`，通过隐藏 PowerShell 引导相同启动入口。只有菜单勾选才创建，不修改系统服务或其他应用的启动项。
- 当前用户应用配置目录下的 `WebNav/runtime/` 保存临时控制描述、最近生命周期状态和自启配置（Windows 默认 `%LOCALAPPDATA%/WebNav/runtime/`），独立于 `WEBNAV_DATA_DIR`。不保存终端输出、服务器认证秘密或全部环境变量；控制令牌仅用于本机管理，均不提交仓库。

托盘管理 WebNav 前后端。网页 RDP 插件自动准备本机 FreeRDP 组件，随会话启动及回收；重启或退出后端会结束它拥有的网页桌面。用户独立打开的 mstsc 不受影响。无需启动 Docker 或外部网关，兼容范围见[网页桌面文档](embedded-desktops.md)。

## 调试与验证

需要终端前台输出时使用 `pnpm dev:console` / `pnpm start:console`，或设置 `WEBNAV_NO_TRAY=1`；Ctrl+C 退出。非 Windows 默认仍以前台方式运行，不模拟 Windows 托盘。前台模式也复用整个现有工作台，不另起 Vite；关闭重复启动的命令不会关闭原实例。`dev:ui` 仅是已有后端的前端调试服务器，不是独立工作台入口。

自动化使用隔离应用配置目录、临时数据库与本机服务，覆盖：并发重复启动、前后端可访问、控制令牌、数据跨重启保存、服务异常退出与恢复、退出释放端口、外部端口占用不误杀、开机启动快捷方式创建/移除、中文空格路径和登录引导脚本。新增跨模式/端口/数据目录启动、直接后端入口、前台先启动后托盘复用、原实例网址打开及浏览器失败不重复打开的验证。浏览器打开函数在测试中记录请求，避免弹出用户浏览器；没有替换用户默认浏览器设置。自启测试使用隔离启动目录，不勾选真实用户自启；未实际注销或重启 Windows，非 Windows 实机行为尚未验收。

实现参考：[Microsoft NotifyIcon](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.notifyicon)、[ApplicationContext](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.applicationcontext)。
