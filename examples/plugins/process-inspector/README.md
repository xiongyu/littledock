# 进程诊断示例

为任务管理器的进程菜单添加“打开扩展诊断”，通过 `api.ui.find` 找到同一目标、启动标识、PID、创建时间的详情实例，再用 `api.ui.activate` 打开自己的标签。也向 `example.ui-extension-host` 的菜单、标签页、面板和操作栏添加内容。

不启动调试器、不附加进程、不执行 Shell。制作 OllyDbg 或其他调试插件时，可复用这些注册方式；真实调试器的安装、进程架构检测、身份复核、确认和会话回收由该插件自己的后端实现。`arch` 为采集器架构，不能据此判断进程位数。

只用于开发与隔离测试，不自动安装。目标插件不存在或契约版本不匹配时，扩展不展示；不影响本插件其他扩展。
