# 本地终端

在工作区使用本机交互终端，自动选择系统 Shell，也可选择 PowerShell、CMD、Bash 或 Zsh。

WebNav 官方内置插件。实现与应用一起构建，提供独立可替换服务及连接器。

管理中心添加「本地终端」入口，选择自动 Shell 或明确指定 PowerShell / CMD 等；工作目录留空为当前用户主目录。Windows 使用 ConPTY，可直接输入中文、调整尺寸和悬浮显示。关闭标签回收本次终端；输出历史默认不保存，可在入口开启。

终端运行在 WebNav 后端所在电脑。不能将本地入口的服务器地址当成远端连接目标。Shell 必须已安装，工作目录必须存在；本地入口不提供 SSH 的 SFTP、系统信息或分屏功能。

详见 [使用与验证](../../../docs/local-adb-wdb.md)。
