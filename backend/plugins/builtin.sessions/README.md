# SSH 终端

通过 SSH 打开交互终端，支持分屏、悬浮窗口、独立显示、主机指纹校验与有界输出背压。

## 功能与边界

连接使用 WebNav 保存的凭据。首次主机指纹需要确认，已知指纹变化必须核验。刷新或关闭主页会结束当前 Shell；历史记录不是可恢复会话。

## 平台与依赖

运行 WebNav 的宿主平台：win32 / x64、win32 / arm64、linux / x64、linux / arm64、darwin / x64、darwin / arm64。平台声明用于兼容筛选，不等于对每个平台都完成了真实远端验收。

依赖：storage、credentials、terminalHistory、connectors、auth。

## 替换与恢复

公开能力：`service:sessions@1`。第三方实现需遵循 [插件规范](../../../docs/plugins.md) 中的服务契约、数据格式和清理要求。插件中心选择提供者，默认在线生效。相关任务或连接使用中时等待结束后自动切换；无法在线替换时显示待重启及原因。

此内置插件随 WebNav 发布，说明和图标从当前安装目录读取，无需访问远程仓库。恢复内置实现不自动迁移或回滚第三方已改写的数据。
