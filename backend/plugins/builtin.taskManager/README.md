# 任务管理器

0.4.0（2026-10-29）：声明独占 Worker，采集与 SSH 业务仅在该线程运行；与系统优化使用不同线程。宿主访问改为异步，连接预算在协调端原子预留，指纹与写入去重在等待后重新核对。详见仓库 docs/plugin-workers.md。

从工作台选择本机或任意已保存的 SSH 连接，查看进程树、CPU、内存、进程资源与支持的结束操作。0.2 版本提供进程/性能视图、整机/逐逻辑处理器曲线、磁盘读写与 GPU；专用显存和共享系统内存独立显示。CPU/内存用绿、黄、橙、红热度帮助定位高占用，浅色与深色面板标题保持明显分层。采集能力按目标平台、驱动和当前用户权限显示，不可读取的数据会注明。

进程前的复选框支持多选，点击「只看勾选进程」固定观察这些进程的 CPU、内存曲线及内存增量；可复制 PID、复制清单、清空勾选和确认后批量结束。点击名称仍单独查看详情，「概览 → 启动参数」可读取、刷新和复制完整命令行，权限不足与不可用会明确提示。0.3.1 提供三平台读取适配；本次新增读取实机验证限 Windows x64。

首次连接缺少采集器时点击安装。Windows、Linux、macOS 均使用目标用户目录下的 `.webnav/tools/task-manager`，按已保存入口建立独立 SSH 连接，验证主机指纹并上传配套采集器，无需目标联网或预装 Node.js。采集器只用标准输入输出通信，不开放网络端口。macOS 首版只读；Windows 提供显式强制结束，Linux 在内核支持时提供普通/强制结束。

0.3 可显式开启目标独立持续监控，默认每 5 秒、最多 7 天/256 MiB，均可调整。关闭页面或断开小站/SSH 后仍记录，再次连接可按时间回溯性能及当时的高占用进程；历史只读，明确显示间断和实际保留范围。停止持续监控保留历史，本轮不注册系统开机项。

关闭视图、锁定或连接失效后只回收即时查看采集器及 SSH；安装文件和已启用的后台记录继续保留。插件更新等待前台采集与安装结束后在线切换。此版本不修改系统快捷键或注册表，不开放任意命令执行接口。详细能力与验收见仓库 `docs/task-manager.md`。
