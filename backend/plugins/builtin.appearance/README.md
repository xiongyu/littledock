# WebNav 默认主题

清爽的灰绿工作台配色。恢复默认界面，保留浏览器里的其他外观方案；内置外观面板还提供浅砂、远山、夜航与雾岚湖畔。

## 使用

在插件市场选择「主题」分类。安装后点击「应用主题」，或从右上角外观设置选择。选择仅保存在当前浏览器，无需重启；随时可恢复默认外观。

## 主题仓库规范

本主题不提供 backend、frontend 或 install 字段。只声明 theme:appearance 能力、三种十六进制配色，以及可选的左右背景图片相对路径。主题背景随 Git 仓库一起安装并保存在本机，已下载资源无需再次访问仓库。

宿主平台组合用于筛选；实际界面由浏览器渲染。图标、说明与代码缓存不会在卸载时自动删除。不会读取账号、服务器或终端内容。
