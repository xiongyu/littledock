# WDB 远程控制

连接 WDB Agent 内置网页服务，在工作区查看 H.264 画面并按需开启键鼠控制。

小站官方内置插件。实现与应用一起构建，提供独立可替换服务及连接器。

管理中心添加「WDB」，填写目标地址、网页服务端口（默认 27880）及 WDB 独立网页管理员账号密码。被控端需完成网页管理员初始化并使用完整模式。「仅管理」模式不提供视频。

首次仅查看，点「仅查看」取得键鼠控制；F8 保留给被控端。被控端未允许控制或不能确认旧输入释放时，显示拒绝原因。新网页登录会替换同一 WDB 的其他网页登录。

密码由小站凭据服务保存，登录 Cookie 与 CSRF 值不进入浏览器。插件不改变已有 AxisAuto 回连或被控端模式；焦点离开、隐藏和断开时释放输入。

详见 [使用与验证](../../../docs/local-adb-wdb.md)。
