# VNC 桌面

使用浏览器打开 VNC，提供桌面会话与一次性票据、显示缩放、键鼠输入和共享桌面通道。

## 功能与边界

VNC 使用 Node TCP 与 RFB 认证，不依赖外部网关。默认支持标准 VNC 密码和无密码认证。实际兼容性取决于远端服务器；网页 RDP 复用其桌面通道。

## 平台与依赖

运行 WebNav 的宿主平台：win32 / x64、win32 / arm64、linux / x64、linux / arm64、darwin / x64、darwin / arm64。平台声明用于兼容筛选，不等于对每个平台都完成了真实远端验收。

依赖：storage、credentials、connectors、auth。

## 替换与恢复

公开能力：`service:desktops@1`。第三方实现需遵循 [插件规范](../../../docs/plugins.md) 中的服务契约、数据格式和清理要求。插件中心选择提供者，默认在线生效。相关任务或连接使用中时等待结束后自动切换；无法在线替换时显示待重启及原因。

此内置插件随 WebNav 发布，说明和图标从当前安装目录读取，无需访问远程仓库。恢复内置实现不自动迁移或回滚第三方已改写的数据。
