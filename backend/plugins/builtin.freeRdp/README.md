# FreeRDP 网页桌面

随应用附带 FreeRDP 本机组件，在浏览器内显示 Windows 远程桌面，支持剪贴板、证书确认与完整帧刷新。

## 功能与边界

宿主需要 Windows x64；这是本机辅助程序的平台要求，不是远端服务器平台。凭据通过 stdin 交接，关闭网页会话后回收本机辅助进程。不自动回退系统客户端。

## 平台与依赖

运行 WebNav 的宿主平台：win32 / x64。平台声明用于兼容筛选，不等于对每个平台都完成了真实远端验收。

依赖：desktops、connectors、storage。

## 替换与恢复

公开能力：`service:freeRdp@1`。第三方实现需遵循 [插件规范](../../../docs/plugins.md) 中的服务契约、数据格式和清理要求。插件中心选择提供者，默认在线生效。相关任务或连接使用中时等待结束后自动切换；无法在线替换时显示待重启及原因。

此内置插件随 WebNav 发布，说明和图标从当前安装目录读取，无需访问远程仓库。恢复内置实现不自动迁移或回滚第三方已改写的数据。
