# SSH 文件管理

通过独立 SFTP 通道管理远端文件，支持上传下载、目录定位、文本编辑与冲突检测。

## 功能与边界

文件操作使用 SFTP，不拼接 Shell 命令。保存前检查远端版本，冲突必须确认。远端文件正文、传输数据与本地编辑副本不进入日志、普通备份或浏览器持久存储。

## 平台与依赖

运行 WebNav 的宿主平台：win32 / x64、win32 / arm64、linux / x64、linux / arm64、darwin / x64、darwin / arm64。平台声明用于兼容筛选，不等于对每个平台都完成了真实远端验收。

依赖：sessions、credentials、sshInspector。

## 替换与恢复

公开能力：`service:sshFiles@1`。第三方实现需遵循 [插件规范](../../../docs/plugins.md) 中的服务契约、数据格式和清理要求。插件中心选择提供者，默认在线生效。相关任务或连接使用中时等待结束后自动切换；无法在线替换时显示待重启及原因。

此内置插件随 WebNav 发布，说明和图标从当前安装目录读取，无需访问远程仓库。恢复内置实现不自动迁移或回滚第三方已改写的数据。
