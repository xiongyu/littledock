# 安卓 ADB

通过本机 ADB 控制 USB 或网络安卓设备。默认增强模式自动推送随附的官方 scrcpy server 3.3.4，显示 H.264 视频，支持触摸拖动、物理键盘、安卓导航键和中文粘贴；也可选择低频 PNG 截图模式。

小站官方内置插件。实现与应用一起构建，提供独立可替换服务及连接器。

先安装 Android Platform Tools，加入 PATH 或设置 WEBNAV_ADB_PATH，手机开启并允许 USB 调试。管理中心添加「安卓 ADB」，读取设备并选择序列号；只有一台已授权设备时可留空自动选择。网络 ADB 使用服务器地址和端口，无线调试需先完成 adb pair。

增强模式默认最长边 1280、上限 60 FPS、8 Mbps；工具栏显示实际呈现 FPS，静止画面可能为 0。首次仅查看，点「仅查看」开启控制；部分手机还需要启用「USB 调试（安全设置）」。文字发送会设置手机剪贴板并粘贴，不自动读取手机剪贴板。

关闭时仅回收本次 scrcpy 服务、文件和转发，不终止全局 ADB。未提供音频、录屏或文件传输。[server 来源与许可证](scrcpy/README.md) · [使用与验证](../../../docs/local-adb-wdb.md)。
