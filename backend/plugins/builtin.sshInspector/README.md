# SSH 系统信息

通过所属 SSH 的独立通道显示 CPU、内存、磁盘和系统信息，并提供有界目录查询。

## 功能与边界

探测使用固定只读命令，不写入交互 Shell 或输出历史。目前探测 Linux / Windows 信息，不支持的远端明确显示不可用。通道随所属 SSH 清理。

## 平台与依赖

运行小站的宿主平台：win32 / x64、win32 / arm64、linux / x64、linux / arm64、darwin / x64、darwin / arm64。平台声明用于兼容筛选，不等于对每个平台都完成了真实远端验收。

依赖：sessions、credentials。

## 替换与恢复

公开能力：`service:sshInspector@1`。第三方实现需遵循 [插件规范](../../../docs/plugins.md) 中的服务契约、数据格式和清理要求。插件中心选择提供者，默认在线生效。相关任务或连接使用中时等待结束后自动切换；无法在线替换时显示待重启及原因。

此内置插件随小站发布，说明和图标从当前安装目录读取，无需访问远程仓库。恢复内置实现不自动迁移或回滚第三方已改写的数据。
