# Windows 远程桌面

调用系统远程桌面客户端，按每个连接入口保存显示设置与凭据，保留系统客户端的独立窗口。

## 功能与边界

仅 Windows 宿主可启动 mstsc。成功启动只表示客户端已启动，不代表远程登录成功。关闭 WebNav 或卸载插件不会终止用户的 mstsc 会话。

## 平台与依赖

运行 WebNav 的宿主平台：win32 / x64、win32 / arm64。平台声明用于兼容筛选，不等于对每个平台都完成了真实远端验收。

依赖：storage、credentials、connectors。

## 替换与恢复

公开能力：`service:rdp@1`。第三方实现需遵循 [插件规范](../../../docs/plugins.md) 中的服务契约、数据格式和清理要求。插件中心选择提供者，默认在线生效。相关任务或连接使用中时等待结束后自动切换；无法在线替换时显示待重启及原因。

此内置插件随 WebNav 发布，说明和图标从当前安装目录读取，无需访问远程仓库。恢复内置实现不自动迁移或回滚第三方已改写的数据。
