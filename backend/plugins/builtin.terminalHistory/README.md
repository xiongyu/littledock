# 终端输出历史

保存 SSH 纯文本输出，按会话查询、搜索、分页，以固定范围查看历史，手动刷新才纳入新输出。

## 功能与边界

默认保留 7 天，单会话 100 MiB、全局 1 GiB（按文本计算，数据库另需空间）。不主动保存输入或认证数据，远端回显仍可能含秘密。不能还原完整 TUI 或恢复 Shell。

## 平台与依赖

运行 WebNav 的宿主平台：win32 / x64、win32 / arm64、linux / x64、linux / arm64、darwin / x64、darwin / arm64。平台声明用于兼容筛选，不等于对每个平台都完成了真实远端验收。

依赖：独立历史数据库。

## 替换与恢复

公开能力：`service:terminalHistory@1`。第三方实现需遵循 [插件规范](../../../docs/plugins.md) 中的服务契约、数据格式和清理要求。插件中心选择提供者，默认在线生效。相关任务或连接使用中时等待结束后自动切换；无法在线替换时显示待重启及原因。

此内置插件随 WebNav 发布，说明和图标从当前安装目录读取，无需访问远程仓库。恢复内置实现不自动迁移或回滚第三方已改写的数据。
