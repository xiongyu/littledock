# 终端配色

为所有 SSH 终端统一管理默认配色、自定义方案与入口级引用，更新颜色无需重连终端。

## 功能与边界

配置通过业务 WebSocket 统一保存在本机。入口引用缺失时回退默认配色，更新不会清理终端输出。替代插件应保留公开配色格式和订阅语义。

## 平台与依赖

运行小站的宿主平台：win32 / x64、win32 / arm64、linux / x64、linux / arm64、darwin / x64、darwin / arm64。平台声明用于兼容筛选，不等于对每个平台都完成了真实远端验收。

依赖：storage。

## 替换与恢复

公开能力：`service:terminalThemes@1`。第三方实现需遵循 [插件规范](../../../docs/plugins.md) 中的服务契约、数据格式和清理要求。插件中心选择提供者，默认在线生效。相关任务或连接使用中时等待结束后自动切换；无法在线替换时显示待重启及原因。

此内置插件随小站发布，说明和图标从当前安装目录读取，无需访问远程仓库。恢复内置实现不自动迁移或回滚第三方已改写的数据。
