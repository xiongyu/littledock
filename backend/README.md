# 后端

此目录承载 WebNav 的本地服务，计划采用 Node.js LTS、TypeScript 和 Cordis。目前只有 `src/` 目录占位，尚未初始化依赖或启动脚本。

## 职责

- Cordis 应用装配、具名服务、连接器注册与资源清理。
- 前端静态资源与 WS 升级握手；HTTP 不承载业务接口。
- WS RPC 注册与分发、主题订阅和状态推送、本地浏览器配对。
- SQLite 元数据、分组和连接管理、导入导出。
- SSH 认证、主机指纹验证、PTY 和会话生命周期。
- 使用当前 Windows 登录用户的桌面会话启动 `mstsc.exe`，或生成 `.rdp` 文件。

实现时在 `src/` 中按 `core/` 和 `plugins/` 组织职责。首版插件随应用打包，配置调整重启生效。

业务插件通过本项目基于 Cordis 实现的 `rpc` 与 `subscriptions` 服务注册方法和发布公开事件；底层 socket 由传输插件统一管理。业务通道与各 SSH 终端通道分离，分别管理流量、鉴权和生命周期，不直接广播内部事件或凭据。

计划只监听 `127.0.0.1`，默认端口 `3030`。数据目录、配置格式、启动和迁移命令在对应能力实现并验证后补充。

详见 [架构方案](../docs/architecture.md)、[WS 协议](../docs/websocket-protocol.md) 与 [开发约定](../AGENTS.md)。
